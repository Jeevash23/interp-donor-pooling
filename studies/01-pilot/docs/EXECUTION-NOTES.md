# Execution notes

The local protocol and deterministic prompt files were hashed before model evaluation. Calibration uses four fixed cases, one from each of the four generated calibration groups, spanning both wording families and both orders. The remaining calibration variants are generated but not evaluated.

The native, hook, identity, duplicate-donor, write-locality, terminal-site and readout-reconstruction checks run before evaluation. **Implementation deviation:** the algebraic decomposition closure check is implemented in the saved-output analysis and therefore runs after scientific inference, rather than as a separate pre-evaluation calibration gate. It does not select outcomes or change any intervention. Both the timing difference and its measured error must be reported. The complete evaluation must pass closure before interpretation or delivery.

The source file frozen in `data/freeze.json` contains only the experiment implementation. Statistical and document scripts are added later; their estimands and inferential rules were already specified by the frozen protocol. They must not be described as fully frozen analysis code. Evaluation uses the entire fixed sample, with no behavioral eligibility gate or removal of low-competence prompts.

The analysis remains exploratory at the project level despite prospective local design choices. No public preregistration, external review, independent researcher replication or publication is claimed.

The post-inference data audit found four donor strings common to generated calibration group 1 and evaluation group 36, with one of those strings actually used by the four-case calibration. Recipient strings do not overlap calibration. These are independently generated draws from the same finite word pools, not disjoint text banks. No scientific settings were selected on calibration behavior, and all 64 evaluation groups remain in the primary result. An initial audit assertion incorrectly required complete string disjointness; that failed audit log is retained, and the assertion was replaced by explicit reporting rather than dropping evaluation rows. A literal scan of 77 earlier structured data files found no new prompt strings, within the documented scan scope.

The independent saved-state readout utility initially assumed a `transformer.` prefix on checkpoint tensor keys. The actual safetensors keys use `wte.weight` and `ln_f.*`; correcting this loader did not change model inference or experimental outputs. The failed utility invocation is retained alongside the subsequent verification.

The initial direct two-dimensional readout agreed with the Transformers readout applied to the same two-dimensional state, but differed slightly from native three-dimensional inference: maximum Small probability error 0.00002775, above the supplemental 0.000005 check. Deterministic settings did not remove that discrepancy. Matching the original batch/sequence tensor shape in the positionwise LayerNorm and unembedding removed it completely: all intervention metrics and comparator endpoints reproduce exactly in both models on the fixed 1,920-state subsets. Other positions are repeated copies solely to match the numerical kernel shape; final LayerNorm is independent across positions. The earlier error records are preserved. No numerical threshold was relaxed and no experimental outcomes changed. A separate JSON serialization error in the audit utility was also fixed without changing calculations.

GPU access succeeded through PyTorch outside the restricted sandbox. The system utility reported an NVML driver/library mismatch. No driver change was attempted. Model inference uses the functioning CUDA runtime and records measured memory and calibration errors.
